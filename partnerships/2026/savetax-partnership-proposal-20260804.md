# [경영진 보고] 세이브택스 제휴 검토 (2026-08-04)

## 1. 개요

| 항목 | 내용 |
|------|------|
| **업체명** | 세이브택스 (SaveTax) |
| **서비스 유형** | 세금 환급 서비스 |
| **제안 담당자** | 유재원 (세이브택스) / 한기태 팀장 (직방) |
| **수익 모델** | RS (Revenue Share) 방식 |
| **작성일** | 2026년 8월 4일 |

---

## 2. 제안 배경

기존에 논의하던 카카오 발송 기반의 채널톡+인앱 결합 구조는 내부 카카오 발송 이슈로 단기 추진이 어려운 상황. 이에 세이브택스 측이 직방 서비스 맥락에 맞게 포지셔닝을 재설계하여 제안을 재정리함.

- 기존 포지셔닝: '외부 세금 환급 광고'
- 재설계 포지셔닝: **'직방 고객의 계약 이후 주거 생활을 지원하는 부가서비스'**
- 고객 진입 키워드: **"지난 5년간 놓친 월세 세액공제 확인"** (직방 유저 친화적)

> 유사 제휴 부동산 관련 업체에서도 '월세 환급' 키워드를 진입점으로 활용 → 실제 통합환급으로 연결하는 방식으로 운영 중

---

## 3. 서비스 범위

1회 인증으로 아래 세목 **통합 조회·환급**:

- 근로자·프리랜서 종합소득세
- 사업자 종합소득세
- 양도소득세
- 종합부동산세
- 취득세 등 부동산 관련 세금

---

## 4. 단계별 제안 구조

### 1차 POC (즉시 추진 가능)

| 항목 | 내용 |
|------|------|
| 노출 지면 | 직방 혜택 지면 |
| 소재 | 월세·부동산 세금 환급 |
| 랜딩 | 직방 전용 공동 랜딩페이지 |
| 수익 구조 | RS 방식으로 성과 검증 |
| 직방 측 역할 | 노출 지면·대상 고객 협의 |
| 세이브택스 측 역할 | 랜딩 제작, 인증, 세무 검토, 신고, CS, 정산 리포트 전담 |

> **핵심**: 별도 개발 및 카카오 발송 불필요 — 직방은 지면 협의만으로 시작 가능

### 2단계 (POC 성과 확인 후)

- 직방 공동 브랜딩으로 인앱 페이지 운영
- 계약 완료·이사·매도 등 **고객 여정별 노출 확대**
- 푸시·CRM·채널톡 결합 상시 운영 검토

---

## 5. 세이브택스 측 준비 현황

- 인앱 제휴 운영 리소스 **준비 완료**
- 기존 직방·호갱노노 지면 집행 실적 보유
- 환급 혜택 명확 전달 소재가 일반 소재 대비 신청 성과 **유의미하게 우수**

## 6. 내부 검토 사항

- [ ] 향후 2단계 인앱 페이지 개발 우선순위 검토

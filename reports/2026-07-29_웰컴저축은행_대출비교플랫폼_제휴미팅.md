## 1. 플랫폼 소개 (웰컴저축은행 측)

웰컴저축은행의 **마이데이터 사업권** 기반으로 운영하는 대출비교 서비스.

- **제휴사 수**: 59개사 (은행, 저축은행, 캐피탈, 금융위 선정 우수대부업체 20개사 포함)
- **월 취급액**: 약 1,000억 원
- **대출 실행률**: 23% (업계 평균 10% 대비 약 2.3배)
- **평균 수수료율**: 1.65%
- **규제 커버리지**: LTV/DSR 규제 외 대출 가능 (우수대부업체 통해 LTV 90%까지)
- **시장 포지션**: 저축은행·캐피탈 2금융권 기준 네이버·핀다 대비 우세, 토스·카카오페이·카뱅 다음 순위

## 2. 제안 비즈니스 모델

### CPS (Cost Per Sale) — 웰컴 측 선호

| 항목 | 내용 |
|------|------|
| 수익 구조 | 대출 실행 금액 기반 수수료의 50% 배분 |
| 파트너 수익률 | 실행 금액의 약 **0.8~0.9%** |
| 예시 | 100억 실행 → 약 9천만 원 광고 수익 |
| 리워드 기간 | 호갱노노 유입 후 **1개월 이내** 실행 시 실적 인정 |
| 추적 방식 | 유입 채널 태그 + CRM 리마인더로 이탈 고객 재접촉 |

### CPA (Cost Per Action) — 직방 측 현재 방식

| 항목 | 내용 |
|------|------|
| 기준 | 가심사(신용) 조회 완료 |
| 단가 | 약 **1만 원/건** |
| 현재 적용 | 직방 ↔ 카카오뱅크 CPA 계약 중 |

## 4. 유저 특성 분석

### 호갱노노 사용자
- 아파트 실거주·보유자 중심, 신용도 양호
- 자가 인증 비율 20% 이상
- MAU 약 **410만 명**
- 대출 승인율·실행율 측면에서 더 적합한 타겟

### 직방 사용자
- 1인 가구, 전·월세 거주자 포함 다양한 인구통계
- 두 플랫폼 유저 중복율 **10% 미만**
- 단기 임대(주·월 단위) 탭 신규 런칭으로 사용자층 더욱 다양화

> **결론**: 호갱노노 유저가 대출 승인율·실행율 측면에서 더 적합한 타겟

## 5. 구현 로드맵

### 1단계 — 배너 광고 테스트 (단기, 즉시 가능)
- 기존 직방/호갱노노 광고 인벤토리에 대출비교 배너 집행
- 클릭수·전환 데이터 확보 → 다음 단계 근거 마련
- CPA 또는 CPS 기반 계약 필요

### 2단계 — WebView 연동 (중기, 내부 보고 후)
- 호갱노노 앱 내 WebView로 대출비교 페이지 연동
- CPS 계약 체결, 퍼널별 데이터 대시보드 공유
- 개발 공수 상대적으로 낮음

### 3단계 — 완전 API 연동 (장기)
- 앱 내 네이티브 경험 구현
- 단계별 DB 입력, 실시간 대시보드 연동
- 개발 공수 높음, 성과 검증 후 진행

## 6. 주요 Q&A 요약

**Q. 현재 규제 환경에서 실효성이 있나?**
> 우수대부업체는 LTV/DSR 규제 외에 있어 LTV 90%까지 담보대출 취급 가능. 은행·저축은행에서 거절된 고객 수요 대응 가능.

**Q. 유저가 이탈 후 다른 플랫폼에서 대출 실행하면?**
> 1개월 내 재유입·실행 시 실적으로 인정. CRM으로 이탈 고객 재접촉 운영 중.

**Q. 웹뷰에서 이탈 고객 추적이 가능한가?**
> 본인 인증 후 당일 유효 알림 발송. 앱 미설치 방식(웹뷰)이라 앱 대비 리텐션에 한계 있으나, 허들이 낮아 진입률은 높음.

**Q. 타 플랫폼 유입 대비 실적은?**
> 토스·카카오페이에서 거절된 고객 재유입 기준, CPS 월 1~2억 원 발생 중.

**Q. 자리톡·담비페이 대비 호갱노노 시뮬레이션은?**
> 호갱노노 클릭수 데이터 제공 시 실적 시뮬레이션 제공 가능. 유저 컨디션이 좋아 실행율은 더 높을 것으로 예상.
